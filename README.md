# Test website

A concept preview built as a static site — plain HTML, CSS and JavaScript, no build step.

- `index.html`, `css/`, `js/`, `images/` — the site
- `_tools/` — small Python helpers for regenerating the menu and secondary pages (not published)
- `_fontlab/` — font comparison sheets (not published); add `?fontlab` to the URL to try the fonts live

Hosted on GitHub Pages from the `main` branch.
